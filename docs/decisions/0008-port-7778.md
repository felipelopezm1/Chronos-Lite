# 0008: Port 7778

**Date:** 2026-11-17. **Status:** accepted.

## The choice

Lite listens on 127.0.0.1:7778 by default (`CHRONOS_LITE_PORT`, `CHRONOS_LITE_HOST`), so it can sit beside full Chronos on 7777.

## Why

The owner may run both. Lite reads its own variables, so a `CHRONOS_PORT` set for full Chronos never moves it.
