# 0002: Apache 2.0

**Date:** 2026-11-17. **Status:** accepted.

## The choice

Chronos Lite is under the Apache License 2.0.

## Why

Chronos carries no licence file of its own, so there was no licence to inherit; Hephaestus Lite is Apache 2.0, and this edition follows it. The brains named in `forge/brains.json` are Apache 2.0 too; the engine (llama.cpp, MIT) and the brains are downloaded, never bundled.
